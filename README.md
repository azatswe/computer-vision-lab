# AirBoard · computer-vision-lab

MVP персональной бесконтактной доски на Python для объяснений, занятий и презентаций.
**Ладонь открывает доску, указательный палец рисует.**

## Быстрый запуск на этом Mac

Окружение и модели уже установлены. Положи **своё фото** с одним хорошо освещённым лицом
в **person.jpg** рядом с app.py (без маски/тёмных очков, желательно анфас).

~~~bash
cd ~/.openclaw/workspace/projects/computer-vision-lab
.venv/bin/python app.py --check
.venv/bin/python app.py
~~~

При запросе macOS разреши камеру Terminal/Python. Если запускаешь из IDE, разрешение
может понадобиться ей. Settings → Privacy & Security → Camera.
Для другой камеры: .venv/bin/python app.py --camera 1.
Для другого фото: .venv/bin/python app.py --person /path/to/photo.jpg.

## Сценарий

1. Встань перед камерой: после трёх последовательных совпадений лица появится **READY**.
2. Покажи **одну открытую ладонь с пятью расправленными пальцами** и удерживай 0,8 секунды.
   Откроется доска; камера останется небольшим превью справа.
3. Оставь выпрямленным **только указательный палец**, остальные согни. Через 0,12 секунды
   начинается штрих. Зелёная рамка в превью камеры — активная зона руки,
   которая отображается на всю доску. Движение зеркальное, как в зеркале.
4. Сожми кулак или убери палец, чтобы переместить руку без линии.
5. Убери ладонь минимум на 0,35 секунды перед новым удержанием: повторный жест возвращает
   камеру на основной экран. Между переключениями — минимум 1,5 секунды. Рисунок сохраняется
   в памяти при переключении, **но не между запусками**.
6. Для созвона вручную включи демонстрацию окна AirBoard в Zoom/Meet/Teams.
   Это обычное окно, **не рисование поверх произвольных приложений и не виртуальная камера**.

Лицо должно оставаться видимым. Потеря совпадения, отсутствие руки или две обнаруженные руки
останавливают штрих. При нескольких обнаруженных лицах жесты отключаются. Переключение
не стирает рисунок. Скачок трекинга начинает новый штрих вместо случайной длинной линии.

## Клавиши (английская раскладка, окно в фокусе)

| Клавиша | Действие |
| --- | --- |
| C | Следующий цвет, всего четыре |
| Z | Отменить последний штрих |
| X, затем X в течение 2 секунд | Очистить доску |
| S | Сохранить только рисунок в exports/airboard-*.png, 1600×900 |
| F | Полноэкранный режим |
| Q / Esc | Выход; несохранённый рисунок потеряется |

Клавиши — локальное управление владельца ноутбука, они не блокируются проверкой лица.
PNG не содержит камеру, лицо, интерфейс или оценку совпадения. Автосохранения нет.
Лимит 40 000 точек ограничивает расход памяти; при достижении сохрани и очисти доску.

## Установка на другой машине

Рекомендуется Python **3.12**, macOS Apple Silicon (на нём проверены библиотеки).
Доступность и работа камеры на Windows/Linux пока не проверены.

~~~bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock.txt
python app.py --download-models
# Затем добавь своё person.jpg
python app.py --check
python app.py
~~~

requirements.txt фиксирует прямые зависимости; requirements.lock.txt — весь проверенный
на macOS/Python 3.12 набор. MediaPipe 0.10.21 выбран ради совместимого Solutions Hands API
со встроенной моделью; это не заявление об использовании самых новых версий библиотек.
Не устанавливай одновременно opencv-python / opencv-python-headless: используется
**opencv-contrib-python** с оконным интерфейсом и FaceRecognizerSF.

Модели YuNet (~0,23 MB) и SFace (~38,7 MB) скачиваются явной командой из OpenCV Zoo,
с фиксированного commit и SHA-256. При обычном запуске сетевых запросов нет.
MediaPipe Hands использует модель из установленного wheel. Установка пакетов/загрузка
моделей требует интернета; дальнейшая обработка локальная.

## Проверки без камеры

~~~bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m pip check
.venv/bin/python app.py --preview exports/preview.png
.venv/bin/python app.py --check  # требует person.jpg, камеру не открывает
~~~

Тесты покрывают классификацию синтетических landmarks, повороты/зеркальность,
задержки жестов, снятие разрешения, несколько рук, границы активной зоны, отмену,
лимит памяти, отсутствие камеры в PNG, ошибки камеры и фото, контрольную сумму,
а также загрузку настоящих ONNX-моделей и inference MediaPipe на пустом кадре.
Синтетический preview не является доказательством работы с реальным человеком.

## Ограничения и приватность

- Фото и признаки лица используются только локально; признаки живут в памяти процесса.
  Фото не загружается на сервер и не включается в Git. Приложение не записывает видео/звук.
- **Это фильтр персонализации, не биометрическая защита.** Нет liveness/anti-spoofing:
  фото на экране или распечатка могут пройти проверку. Не связывай жест с оплатой,
  дверным замком, секретами или другими чувствительными действиями.
- Обнаружение одного лица и одной руки **не доказывает, что рука принадлежит этому лицу**.
  MVP рассчитан на одного человека перед ноутбуком, не на многопользовательскую сцену.
- Cosine similarity — не вероятность/процент уверенности. Порог по умолчанию 0.45;
  --threshold позволяет его настроить. Понижение повышает риск ложных совпадений.
  Сначала улучши освещение/эталонное фото, а не понижай порог.
- Жесты эвристические: лучше ладонь фронтально к камере, пальцы не перекрывают лицо.
  Качество распознавания и FPS на реальной камере нужно откалибровать на пользователе.
- Интерфейс MVP на английском из-за ограничений встроенного шрифта OpenCV;
  инструкция и ошибки запуска — на русском.
- Рисунок остаётся видимым при потере лица; блокируется ввод, а не просмотр.

## Структура и источники

- app.py: CLI, камера, цикл окна, клавиши и освобождение ресурсов.
- airboard/vision.py: YuNet + SFace и MediaPipe Hands.
- airboard/core.py, session.py: тестируемые жесты и состояния.
- airboard/ui.py: доска, интерфейс, экспорт PNG.
- airboard/models.py: явная загрузка/проверка моделей.
- tests/: unit/integration smoke tests без физической камеры.

Использованы готовые open-source компоненты вместо обучения собственных сетей:
[OpenCV Zoo](https://github.com/opencv/opencv_zoo),
[MediaPipe](https://github.com/google-ai-edge/mediapipe),
[OpenCV](https://opencv.org/).
Файлы лицензий моделей скачиваются рядом с моделями в models/*-LICENSE;
при распространении соблюдай их условия и лицензии зависимостей.

Следующая итерация после проверки MVP: калибровка жестов на реальной камере,
затем страницы доски/сохранение сессии. Управление чужими приложениями не входит в MVP.
